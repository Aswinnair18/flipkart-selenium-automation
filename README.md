# Flipkart Selenium Automation

Professional UI automation framework using Java, Selenium WebDriver, TestNG, Maven and Page Object Model (POM).

## Tech Stack
- Java 17
- Selenium WebDriver 4.35.0
- TestNG 7.11.0
- Maven
- Page Object Model

## Run Tests
```bash
mvn clean test
```

## Test Coverage
- Homepage load and title validation
- Product search validation
- Search results validation

## Project Structure
```text
src/main/java/pages/
src/test/java/tests/

testng.xml
README.md

```
